Before you send the chat.

Who sees our chat?

There is no CHATCOM server. It runs on one friend’s computer. The model that writes the episode reads the chat: that friend’s Claude Code session, or Anthropic and Google with their own keys. CHATCOM shows exactly where it goes and waits for a yes before it sends anything.

Does everyone have to sign up?

No. One friend sends in the chat and shares the episode back to the group.

Which chats work?

WhatsApp and Telegram exports, screenshots from any app (Signal, iMessage, Discord and the rest), or a chat you paste in.

What do I need?

Claude Code. CHATCOM runs as a Claude skill on your computer. If you would rather run it outside Claude Code, use your own API keys and pay the models directly. CHATCOM has no keys of its own.

Is it ready?

Version 0.1 is in development. Watch the repo on GitHub to get it the day it ships.
